# Getting help

- **Module 0 (open to everyone):** ask questions in [Module 0 Discussions](https://github.com/m74-academy/module-0/discussions). Report a mistake in a lesson or a setup problem by opening an [issue](https://github.com/m74-academy/module-0/issues) with the matching template.
- **Academy students:** open an issue in the module repository with the matching template for a mistake in a lesson or a setup problem. Ask course questions in that module's Discussions when it has them; otherwise ask your instructor.
- **Personal matters:** contact your instructor, or write to [virgil.sisoe@m74post.com](mailto:virgil.sisoe@m74post.com).

Setup, Git, and Python guides are in the [M74 Academy guides](https://github.com/m74-academy/community). Include the command you ran, the full output, your operating system, and the lesson you were on.
